# Subscription Tracker Frontend

Интерфейс на React/Vite для управления подписками KeyNeroCity.

## Возможности

- Современный UI с Tailwind CSS и плавными анимациями Framer Motion
- Добавление, редактирование и удаление подписок
- Просмотр статистики по количеству подписок и суммарной стоимости
- Ручный запуск email-напоминания в один клик

## Запуск

```bash
cd frontend
npm install
npm run dev
```

Фронтенд по умолчанию ожидает backend на `http://localhost:5000`. Изменить URL можно через переменную окружения `VITE_API_URL`.
