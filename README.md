# NeuroSubs

NeuroSubs — это мини-приложение для отслеживания подписок на нейросервисы с тёмной эстетикой и уведомлениями на e-mail.

## Возможности

- хранение информации о подписках: цена, цикл оплаты, следующая дата, заметки;
- напоминания по e-mail за заданное количество дней до даты оплаты;
- панель с карточками в тёмном стиле и пометками о статусе (активна, скоро оплата, просрочена);
- отдельный скрипт для ручного запуска уведомлений.

## Запуск проекта

1. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Linux/macOS
   .venv\\Scripts\\activate   # Windows
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Заполните переменные окружения (можно создать файл `.env`):

   ```env
   SECRET_KEY=замените-на-секрет
   SMTP_SERVER=smtp.yourmail.com
   SMTP_PORT=587
   SMTP_USERNAME=bot@yourmail.com
   SMTP_PASSWORD=пароль
   SMTP_USE_TLS=true
   NOTIFIER_EMAIL_FROM=bot@yourmail.com
   ```

   Если SMTP не настроен, скрипт выведет текст письма в консоль.

4. Запустите сервер разработки Flask:
   ```bash
   flask --app app run
   ```

   При запуске напрямую через `python app.py` поднимется сервер и фоновый планировщик, который ежедневно в 9:00 проверяет подписки.

5. Добавляйте подписки через веб-интерфейс. Фоновый планировщик или отдельный скрипт будет отправлять (или выводить) напоминания.

## Ручной запуск уведомлений

Можно вручную проверить уведомления, выполнив:

```bash
python notify.py
```

Скрипт использует те же настройки и отправит письма/выведет уведомления для подписок, у которых близкая дата оплаты.
